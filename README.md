## 🧭 Where it started

I got into development by experimenting with websites and building things of my own.

As I continued learning, I started building **applications with Python** as well. I enjoy using Python to develop practical tools and application logic, and HTML, CSS, Vue and React to build websites and interfaces. Working with both has helped me explore different ways of turning an idea into something functional.

Around **2021**, I also got into **content creation and video editing**, experimenting with editing videos and learning how to create and put content together.

My interests and projects evolved as I kept learning. I went from modifying games and experimenting with websites to becoming interested in broader software development — and eventually in the systems that software depends on.

Some of my earlier website work is still available in my repositories. It reflects that early period of experimenting, learning through trial and error, and building things because I wanted to see if I could.
